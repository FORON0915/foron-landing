# 포온 (PawON) — Landing Page

반려동물 맞춤 추천 플랫폼 **포온(PawON)**의 소개용 랜딩 페이지입니다.

> "아이들에게 당신은 세상의 전부입니다. 포온은 그 선택을 함께합니다."

## 소개

포온은 강아지·고양이의 품종, 나이, 건강 상태에 맞춰 사료·간식·영양제·용품을 추천하는
반려동물 맞춤 큐레이션 서비스입니다. 이 저장소는 서비스 소개를 위한 단일 페이지
랜딩 사이트(`index.html`)를 GitHub Pages로 배포하기 위한 것입니다.

## 배포

이 저장소는 GitHub Pages(`main` 브랜치, 루트 경로)로 배포됩니다.

## 구성

- `index.html` — 랜딩 페이지 본문
- `README.md` — 이 문서
